# Локальные материалы восстановления

Этот каталог предназначен только для локальных снимков и пакетов, которые могут
потребоваться для восстановления истории или проверки ранее сохранённых данных.
Они не являются исходным кодом, зависимостью сборки или источником текущей
функциональности проекта.

Отслеживаемым файлом остаётся только этот документ. Все вложенные каталоги,
двоичные архивы и Git bundle игнорируются через `.gitignore` и не должны
попадать в коммиты или pull request.

Локальные материалы размещаются по схеме
`artifacts/recovery/<дата-и-задача>/`. Перед использованием двоичного пакета
нужно сверить его SHA-256 и выполнить профильную проверку формата, например
`git bundle verify` для Git bundle.

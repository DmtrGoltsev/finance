# Security Workspace

Ownership: security evidence and DevSecOps workers assigned by the orchestrator only.

Expected future contents:

- Security scan configuration and outputs.
- Runbooks for CSRF/CORS checks, token/session evidence, log/audit privacy scans, secret scans, dependency scans, and release-blocker triage.
- Links or references to evidence under `artifacts/evidence/security/` and `artifacts/evidence/dependencies/`.

Do not place secrets, tokens, real financial data, raw request/response bodies, or private evidence extracts in this directory.

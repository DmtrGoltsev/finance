- Реальный локальный HTTP-запрос к шлюзу не получает ответ до завершения обещания COMMIT; ошибка приёма не возвращает успех. JSON разбирается после HMAC.
- Повтор события, повтор nonce, конфликт содержимого, последовательность попыток и предел 3 проверены модульными тестами. SQL использует блокировку по заданию, уникальные ограничения и `SKIP LOCKED`.
- Проверены частные/зарезервированные IPv4/IPv6, подмена DNS между разрешением и соединением, смешанный публичный/частный DNS-ответ, запрет redirect и превышение размера ответа.
- Проверены отсутствие/устаревание официального времени MOEX, неверный JSON модели, дополнительные поля `assumptions`, неправильные типы, агрегаты и суммы.
- Проверен успешный путь `collecting → analyzing → ready` с подписью callback; восстановление сохранённого callback не запускает модель заново.
- Проверены исключение персональных полей, отсутствие идентификаторов задания в пакете провайдера, шифрование очереди, защита от подмены шифротекста и обезличенные ошибки HTTP.
- `npm run validate`: три процесса без Code nodes, с постоянными ID, передачей raw binary и ответом только после gateway.
- `npm run test:import`: действительно выполнены три команды `n8n@2.39.8 import:workflow` и `export:workflow --all` во временном профиле SQLite. Все три ID сохранены, процессы неактивны. Временный профиль удалён.

- Наличие базового образа `node:22.22.0-alpine3.23` подтверждено через `docker manifest inspect`.

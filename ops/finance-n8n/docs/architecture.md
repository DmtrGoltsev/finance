# Архитектура Finance → n8n → DeepSeek → Finance

## Поток

1. Пользователь подтверждает распознанный портфель в Finance.
2. Backend создаёт долговечное задание и outbox-событие.
3. Worker backend формирует envelope версии 1, подписывает его HMAC и отправляет во внутренний webhook n8n.
4. n8n проверяет timestamp, nonce, подпись, точную схему, возраст до 24 часов и отсутствие чувствительных полей.
5. PostgreSQL n8n атомарно захватывает `eventId`; другой payload с тем же ID отклоняется.
6. n8n сообщает Finance состояния `collecting` и `analyzing` подписанными callback.
7. Рыночные данные загружаются только по фиксированным HTTPS URL без redirect. Лимит ответа — 1 МиБ, timeout — 10 секунд, максимум три попытки.
8. DeepSeek получает обезличенный пакет, проверенный рыночный набор и детерминированный cash-first расчёт.
9. Ответ DeepSeek проверяется строгой JSON-схемой, allowlist инструментов, агрегатами и суммами действий.
10. Готовый или ошибочный результат подписывается и возвращается Finance. Backend повторно проверяет контракт и становится владельцем результата.
11. Backend создаёт собственное событие Android push с нейтральным текстом.

## Идемпотентность и повторы

- Ключ n8n — `eventId`, содержимое связано с SHA-256 канонического JSON.
- Точный повтор активного или завершённого события не запускает второй анализ.
- Повтор с тем же `eventId`, но другим hash, `jobId` или attempt отклоняется.
- Незавершённый технический lease можно повторно захватить после 15 минут.
- HTTP рыночных источников, DeepSeek и callback имеют до трёх ограниченных попыток.
- После ошибки n8n возвращает `retryable=true`, только если `attempt < 3`; новый attempt создаёт backend Finance.

## Защита от SSRF

Процесс не выполняет URL из входного payload или ответа модели. Рыночные адреса заданы в runtime. Для каждого ответа запрещены redirects, нестандартный порт, credentials в URL, fragment и ответ больше 1 МиБ. Частные IP и произвольные домены отклоняются контрактным слоем. Новостные домены технически перечислены, но fail-closed выключены переменной `NEWS_SOURCES_ENABLED=false`.

## Изоляция

- PostgreSQL виден только в `finance_n8n_private`.
- n8n подключён к приватной БД, отдельной backend-сети и отдельной egress-сети.
- Редактор привязан к loopback; внутренние webhook не публикуются Caddy.
- Docker socket, shell-исполнители, произвольные external modules и OpenClaw отсутствуют.
- В `.env.example` нет рабочих секретов.
